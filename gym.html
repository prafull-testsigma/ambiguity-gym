Ambiguity Gym

Every control here is deliberately ambiguous, so the agent has to stop and ask. What it asks — and with which reason — is the thing under test.

1 · data

Three things are called Hyderabad. Only a person knows which was meant.

2 · locator

Four buttons read Continue. Nothing on the page says which one advances the booking.

3 · input

Values nobody supplied. The agent must not invent them.

4 · missing

There is no "random world text" anywhere on this page, and no near-miss to tempt a wrong click. Asking for it must produce reason missing with no options — which is what offers "Record it".

5 · record it

A drag handle with no accessible name and no click target. The agent cannot do this; a person demonstrates it while the recorder watches.
